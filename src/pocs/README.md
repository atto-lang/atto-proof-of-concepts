# Starter Oreslang source samples

These are native `.ores` source examples, reused from live Oreslang compiler example inputs and the linked-queue implementation. They are **prototypes, not CI-validated fixtures in this repo**. Included: closure capture and recursion, async/await, classes/contracts/generics and a bounded linked queue in `../libraries/oreslang-linked-queue`.

The original source uses both legacy and canonical syntax. Future formatter/compiler runs must establish acceptance on each backend.
