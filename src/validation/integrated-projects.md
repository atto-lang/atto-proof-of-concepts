# Integrated projects

1. Graph editor: graphs, undo/redo, visitor, closures, serialization.
2. Actor banking system: ledgers, supervisor trees, distributed transactions, replay.
3. Self-hosted interpreter: lexer, AST, scope, closures, generics and pattern matching.
4. Async HTTP server: network, streams, middleware, cancellation.
5. Embedded KV database: B+ tree, cache, WAL and recovery.
6. Actor-based scheduler: work stealing, futures, mailboxes and task ownership.

Each requires its own invariant, adversarial tests, cross-backend command and failure artifact before claiming readiness.
