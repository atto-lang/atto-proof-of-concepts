# Oreslang proof of concepts

[Source catalog](src/README.md): 60 library briefs and **70 pattern source prototypes** with individual output oracles. [Runner and evidence policy](src/patterns/EXECUTING.md). [Pinned Java runtime audit](src/patterns/COMPILER_TIP_AUDIT.md) records **70/70 real guest executions**, which test sample outputs rather than the named patterns' full safety properties.

The GitHub Actions structural workflow checks file/catalog integrity only, **not** whether the Oreslang compiler or runtime can execute these programs.
